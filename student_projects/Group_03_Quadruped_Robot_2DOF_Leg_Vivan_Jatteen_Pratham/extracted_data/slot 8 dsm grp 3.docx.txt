3. Sensitivity Analysis
Sensitivity analysis was conducted to study how variations in input parameters affect the system output.
Parameters varied:
Link lengths
Joint angles
Input position of the foot
Observations:
Small variations in joint angles resulted in noticeable changes in foot position, indicating high sensitivity.
Link length variations significantly affected reach and workspace.
The system showed predictable and stable behavior for small perturbations.
Conclusion:
The model is sensitive but stable, and behaves as expected for a multi-link mechanical system.
