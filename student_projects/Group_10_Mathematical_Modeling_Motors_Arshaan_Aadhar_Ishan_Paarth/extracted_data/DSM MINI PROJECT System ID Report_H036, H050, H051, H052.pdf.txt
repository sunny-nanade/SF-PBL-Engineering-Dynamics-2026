System Identification Report: Motor Modelling
1. System Selection and Approval
The system we chose is a motor modelling system. It has three types of motors: DC motor,
stepper motor and servo motor.
This system is in Category E(Digital Twins / Electromechanical Systems). We picked it to study
how electrical and mechanical parts work together. The system is approved for modelling,
simulation and validation by our faculty.
2. Real-World Application
These motors are used in things like robotics, automation and control systems:
• DC motors are used for things that need to keep rotating, like fans and conveyors.
• Stepper motors are used for movements like in 3D printers and CNC machines.
• Servo motors are used in systems that need feedback like robot arms and drones.
This project is about modeling and comparing how these motors behave under conditions.

4. Degrees of Freedom (DOF)
The DOF is 1 for all three motors.
Justification:
Each motor has one kind of motion which is the rotation of its shaft.
All system dynamics are described using one angular coordinate θ.
5. Key Assumptions
• Motors are treated as bodies.
• Magnetic effects are simple and constant.
• Friction is like viscous and changes, with velocity.
• Electrical parts like resistance and inductance are constant.
• There are no disturbances except load torque.
• Temperature effects are ignored.
• Stepper motor is modeled using a torque relation.
• Servo motor feedback is assumed to be ideal.
• The system operates within limits.
