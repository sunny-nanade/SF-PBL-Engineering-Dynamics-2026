Q1: What was the single hardest technical challenge you faced
in deriving the mathematical model? How did you resolve it?
The hardest technical challenge was accurately deriving the
velocities and for each link in a multi-DOF, coupled system
without making errors. Even small mistakes in kinematics
would affect the entire Lagrangian and final equations. This
was resolved by systematically defining the reference frames
Q2: Which Course Outcome (CO1-CO5) was most
challenging for your team? Why?
The most challenging course outcome for this project is CO4:
applying constitutive laws to analyze dynamic systems . This
is because the humanoid robot is a multi-DOF system with
nonlinear and coupled dynamics, making the Euler–Lagrange
formulation complex. It requires accurate derivation of
energies, velocities, and equations of motion, which is
significantly more difficult than standard problems.
Q3: What would you do differently if you started the project
over?
If I started the project again, I would begin with a simpler
model, such as a reduced DOF system, and then gradually
increase complexity. I would define reference frames and
generalized coordinates more systematically at the start to
avoid confusion later. would plan the derivation in a more
structured way, breaking it into smaller steps and validating
each stage before proceeding.
Q4: What did you learn from this project that a regular
textbook problem could NOT teach you?
I learned how to model a multi-DOF system where all joints
are coupled, how small mistakes in kinematics or energy
terms can completely affect the final equations, and how
important it is to define reference frames and coordinates
correctly from the start . It included dealing with assumptions,
simplifications, and validation using simulations
