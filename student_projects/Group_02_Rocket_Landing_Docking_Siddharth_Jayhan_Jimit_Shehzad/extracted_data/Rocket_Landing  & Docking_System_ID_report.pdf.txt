SYSTEM ID REPORT
(ROCKET LANDING SYSTEM)
1. SYSTEM DESCRIPTION
The system is a rocket landing model designed to simulate vertical take-off, hover, and
controlled landing using thrust vector control.
The rocket is modeled as a rigid body system and is controlled using PID-based feedback
control implemented in a Python–PyBullet environment.
The system accounts for gravity, drag, and wind disturbances, enabling realistic simulation
of aerospace landing dynamics.
The primary objective is to achieve stable hover and precise landing through control of
thrust and orientation.

4. ASSUMPTIONS
• Rocket behaves as a rigid body
• Motion is planar (no yaw)
• Small angle approximation is valid
• Thrust acts along rocket body axis
• Drag is proportional to velocity
• Mass remains constant
• External disturbances modeled as wind forces

6. WORKING PRINCIPLE
The system operates using closed-loop feedback control.
• During lift-off, thrust overcomes gravity
• During hover, thrust balances forces
• During descent, thrust is reduced to control velocity
The controller continuously adjusts thrust and gimbal angle based on system state to ensure
stable and accurate landing despite disturbances.
